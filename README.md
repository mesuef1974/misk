# مسك

النشاط التجاري للحفر بالليزر في قطر: كفرات جلد طبيعي نباتي الدباغة، وتوزيعات المناسبات، على xTool P2S.

فُصل عن المحرّك التقني [local-pen-studio](https://github.com/mesuef1974/local-pen-studio) في 2026-11-16، وتاريخه منقول من مجلد `laser-cases/` هناك. المحرّك لا يحمل بيانات زبائن، وكل ما فيه اسم شخص يبقى هنا خارج git.

الاعتماديات: `pip install -r requirements.txt`.

- `laser-cases-brief.html`: ملخص الشريكين (الترخيص، السوق، الحساب، الخامات، التوريد).
- `laser/توزيعات_المناسبات.html`: الخط الثاني بالتوازي مع الكفرات: توزيعات الأعراس والمواليد بالليزر، ومقوّماتنا لها.
- `samples/`: ملفات SVG لعيّنات التوزيعات على xTool P2S (بطاقة مقوّسة، ميدالية حرف، غطاء برطمان)، وصفحتها `samples/index.html`، ومولّدها `samples/build_samples.py`. وعيّنات كفرات الجلد (قصاصة اختبار، وتصميمان لآيفون 17 وجالكسي S25) في `samples/جلد.html` ومولّدها `samples/build_leather.py`.
- `laser/السوق_المحلي_للحفر.md` و`laser/توريد_الكفرات.md` و`.html`: بحث السوق والتوريد.
- `build/build_laser_letters.js` (محلي، غير متتبَّع لأنه يحمل أسماء الشريكين): يولّد طلبي إذن الوزارة وأسئلة وزارة التجارة بصيغة Word في `laser/`. يحتاج حزمة `docx` من npm، وهي غير مثبتة في المستودع.

الملفات المولَّدة وسكربتها (`laser/*.docx` و`laser/*.pdf` و`build/`) تحمل أسماء أشخاص، فهي متجاهَلة في git وتبقى محلية.
