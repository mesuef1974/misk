# حفر الكفرات بالليزر

مشروع تجاري مرافق لاستوديو المسارات: حفر أسماء على كفرات جلد طبيعي نباتي الدباغة في قطر.

- `laser-cases-brief.html`: ملخص الشريكين (الترخيص، السوق، الحساب، الخامات، التوريد).
- `laser/توزيعات_المناسبات.html`: الخط الثاني بالتوازي مع الكفرات: توزيعات الأعراس والمواليد بالليزر، ومقوّماتنا لها.
- `laser/السوق_المحلي_للحفر.md` و`laser/توريد_الكفرات.md` و`.html`: بحث السوق والتوريد.
- `build/build_laser_letters.js` (محلي، غير متتبَّع لأنه يحمل أسماء الشريكين): يولّد طلبي إذن الوزارة وأسئلة وزارة التجارة بصيغة Word في `laser/`. يحتاج حزمة `docx` من npm، وهي غير مثبتة في المستودع.

الملفات المولَّدة وسكربتها (`laser/*.docx` و`laser/*.pdf` و`build/`) تحمل أسماء أشخاص، فهي متجاهَلة في git وتبقى محلية.
